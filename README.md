# ArvexaLabs - Dijital Dönüşüm Platformu

**Tam Kapsamlı Site Özeti - Her Section'ın Detaylı İçeriği**

ArvexaLabs'nun modern, profesyonel landing page'i. Next.js, TypeScript, TailwindCSS ve GSAP animasyonları ile geliştirilmiş, dijital dönüşüm çözümleri sunan premium bir yazılım ajansı web sitesi.

## 🌟 **Site Genel Özellikleri**

- **Modern Tasarım**: Siyah arka plan, cyan/teal renk paleti, glassmorphism efektleri
- **GSAP Animasyonları**: Scroll-triggered animasyonlar, parallax efektleri, hover etkileşimleri
- **Tam Responsive**: Mobile-first tasarım, tüm cihazlarda mükemmel çalışır
- **SEO Optimize**: Kapsamlı meta etiketleri ve performans optimizasyonları
- **TypeScript**: Uygulama genelinde tam tip güvenliği
- **Üretim Hazır**: Performans ve deployment için optimize edilmiş

## 📦 **Kurulum ve Yapılandırma**

### **1. Repository'yi Klonlayın:**
```bash
git clone <repository-url>
cd elitecode-studio-landing
```

### **2. Bağımlılıkları Yükleyin:**
```bash
npm install
```

### **3. Environment Variables'ı Ayarlayın:**
```bash
cp .env.example .env.local
```

**.env.local içeriği:**
```env
# Email Configuration for Nodemailer
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your-email@gmail.com
SMTP_PASS=your-app-password

# Contact email where messages will be sent
CONTACT_EMAIL=hello@arvexalabs.com

# Optional: Send confirmation email to users
SEND_CONFIRMATION_EMAIL=true
```

### **4. Geliştirme Sunucusunu Başlatın:**
```bash
npm run dev
```

### **5. Tarayıcıda Açın:**
[http://localhost:3000](http://localhost:3000)

## 🌍 **Internationalization (i18n)**

ArvexaLabs, `next-intl` kullanarak çoklu dil desteği sunar. Şu anda Türkçe (tr) ve İngilizce (en) dilleri desteklenmektedir.

### **1. Kurulum ve Yapılandırma**

`next-intl`'i projenize entegre etmek için aşağıdaki adımları izleyin:

#### **1.1. Gerekli Paketleri Yükleyin**
```bash
npm install next-intl
```

#### **1.2. Dil Yapılandırması (`i18n.ts`)**

`i18n.ts` dosyası, uygulamanın desteklediği yerel ayarları ve mesaj dosyalarını yapılandırır. Projenizin root dizininde (`./`) bu dosyayı oluşturun:

```typescript
// i18n.ts
import { notFound } from 'next/navigation';
import { getRequestConfig } from 'next-intl/server';

export default getRequestConfig(async ({ locale }) => {
  // Uygulamanızda desteklenen dilleri burada tanımlayın
  if (!['en', 'tr'].includes(locale as any)) notFound();

  return {
    messages: (await import(`./messages/${locale}.json`)).default
  };
});
```

#### **1.3. Middleware (`middleware.ts`)**

`middleware.ts` dosyası, gelen isteklerin dilini belirler ve uygun şekilde yönlendirme yapar. Projenizin root dizininde (`./`) bu dosyayı oluşturun:

```typescript
// middleware.ts
import createMiddleware from 'next-intl/middleware';

export default createMiddleware({
  // Uygulamanızda desteklenen tüm dillerin listesi
  locales: ['en', 'tr'],

  // Eşleşen bir dil bulunamadığında kullanılacak varsayılan dil
  defaultLocale: 'tr'
});

export const config = {
  // Yalnızca uluslararasılaştırılmış yolları eşleştirin
  matcher: ['/', '/(tr|en)/:path*']
};
```

#### **1.4. Root Layout (`src/app/[lang]/layout.tsx`)**

`src/app/[lang]/layout.tsx` dosyası, `next-intl` mesajlarını yükler ve uygulamanın genel yapısını oluşturur. `src/app` dizininin altında `[lang]` adlı bir klasör oluşturup `layout.tsx` dosyasını bu klasöre taşıyın ve içeriğini aşağıdaki gibi güncelleyin:

```typescript
// src/app/[lang]/layout.tsx
import type { Metadata } from 'next';
import { Inter } from 'next/font/google';
import '../globals.css';
import { NextIntlClientProvider } from 'next-intl';
import { getMessages } from 'next-intl/server';

const inter = Inter({ subsets: ['latin'] });

export const metadata: Metadata = {
  title: 'ArvexaLabs - Digital Transformation',
  description: 'AI-powered web development, mobile apps, and SEO solutions.',
};

export default async function LocaleLayout({
  children,
  params: { lang }
}: {
  children: React.ReactNode;
  params: { lang: string };
}) {
  const messages = await getMessages();

  return (
    <html lang={lang}>
      <body className={inter.className}>
        <NextIntlClientProvider messages={messages}>
          {children}
        </NextIntlClientProvider>
      </body>
    </html>
  );
}
```

#### **1.5. Root `src/app/layout.tsx` Dosyasını Güncelleyin**

Orjinal `src/app/layout.tsx` dosyasının içeriğini aşağıdaki gibi güncelleyerek sadece html ve body etiketlerini ve gerekli metadata'yı tutmasını sağlayın. Dil parametresini artık `[lang]/layout.tsx` ele alacaktır.

```typescript
// src/app/layout.tsx
import './globals.css';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return children;
}
```

#### **1.6. Sayfa Bileşenlerini Güncelleyin**

Hero, Services, WhyWorkWithMe, Pricing, AISEOPerformance, Portfolio, Contact, CTABanner ve Footer gibi tüm sayfa bileşenleri, `useTranslations` hook'unu kullanarak içeriği çeviri dosyalarından alır. Her bir bileşenin en üstüne `'use client';` direktifini ekleyin ve aşağıdaki gibi `useTranslations` hook'unu kullanarak metinleri çeviri anahtarlarıyla değiştirin:

```typescript
// src/components/Hero.tsx
'use client';
import { useTranslations } from 'next-intl';

export default function Hero({
  params: { locale }
}: { // Add params with locale to Hero component prop type
  params: { locale: string };
}) {
  const t = useTranslations('hero');
  // ...
  return (
    <h1>{t('title_part1')} <span className="...">{t('title_part3')}</span></h1>
  );
}
```
